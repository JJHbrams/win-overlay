# Mia 참조 및 입력

- 루트의 v22 PNG 세 장은 승인된 Mia 컨셉·표정·전신 원화다. 최종 Blender 파일에도 같은 원본 바이트가 패킹되어 있다.
- `inputs/`의 v30 정면/후면 A-pose는 승인 원화를 바탕으로 OpenAI ImageGen에서 제작한 3D 재구성 입력이다.
- `conditioning/`은 선택된 body/head 로컬 재구성에서 실제로 사용한 전처리 이미지다. 투영 도구의 기본 입력도 이 폴더를 사용한다.
- `files.json`은 이 참조 이미지들의 상대 경로와 SHA-256을 기록한다.

캐릭터 디자인을 참고하기 위해 대화에 첨부했던 타 캐릭터·실사 사진은 이 폴더에 포함하지 않는다. 원본 GLB·모델 체크포인트는 배포하지 않는다. 생성 당시 절대 경로와 모델 관찰 기록은 `../blender/mia-rig-draft-v45/provenance/`에 있다.
