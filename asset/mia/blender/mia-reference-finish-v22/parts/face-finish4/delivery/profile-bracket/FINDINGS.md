# Read-only source SIDE camera bracket

The frozen finish4 native was rendered at yaw60/70/80/90, elevation0, roll0, orthographic scale0.29, same common root lighting. Each column uses a uniform eye-to-chin SRT only; the source SIDE eye/chin estimates are ±2 original pixels. No model was saved or changed.

The hair-on60–70 views reveal more iris than80–90, but still do not expose the complete source-style eye. Hair-hidden80–90 retain substantial iris visibility. Thus the loss of the eye in the earlier80-degree hair-on comparison is strongly affected by the unchanged hair placement; it is not sufficient evidence to shrink, move or flatten the eye.

The source combines a side-like face silhouette with a comparatively frontal/stylized exposed eye. No one angle in this bracket matches all of its hair occlusion, eye drawing, nose/philtrum and jaw. The prior70–90 estimate was uncertain, not a calibrated camera. This bracket expands the evidence to60; it does not establish60 as the correct source camera.

The broad cheek/temple surface and residual nose/mouth stylization differences remain visible with hair hidden. Camera uncertainty does not remove those differences. No new geometry correction is selected from this diagnostic alone.

`comparison-registration.json` records source crop/hash, manual anchors, per-column uniform SRT and PNG hashes. `camera-records.json` contains actual camera matrices and numerical root lighting. Its generic obsolete fixed-normal helper description was replaced during composition with the actual common rig record; camera/native data were unchanged.
