# Mia 얼굴·두상·Pixal 헤어 수정본 v17–v18

정적 조형과 표면 수정 체크포인트다. 전체 캐릭터 완성, 최종 헤어 토폴로지, 표정·헤어 리깅 또는 이벤트 애니메이션 완료를 뜻하지 않는다. 기존 원화와 이전 native는 보존했다.

**현재 판정: 얼굴·헤어·바디 원화 정합 FAIL.** 아래 수정량과 기술 검사는 제작 이력이며 원화 일치의 증거가 아니다. 최신 대응 비교와 정정은 [v19 검토](../mia-reference-validation-v19/README.ko.md), 다음 작업은 [CURRENT_STATE](../../CURRENT_STATE.json)를 우선한다. 눈 감기 때 속눈썹/페인트/안구 연결도 미완료이며 의상·최종 리깅으로 승격하지 않는다.

- `integrated-v18/integration-manifest.json`: 입력 native와 출력 해시, 교체하지 않은 모든 메시의 좌표·토폴로지·기존 UV·키·웨이트·재질 소유권 보존 검사.
- `integrated-v18/live-integration-evidence.json`: 실제 설치된 Blender MCP로 새 native를 저장하고 live 다각도 캡처한 기록. 사용자에게 테스트 뷰 상태 폐기 권한을 받아 진행했다.
- `integrated-v18/fresh-review/`: 저장 파일을 다시 열어 렌더한 실제 비교와 UV/클레이 증거. 렌더 후 native를 저장하지 않는다.

- `evidence/`: 제작 작업 공간의 동결된 형상·UV·전이 검증 결과 사본.

## v18 얼굴 폭과 홍채 수정

원화보다 넓은 얼굴, 작은 홍채, 사선에서 눈 바깥쪽→볼이 갑자기 꺾이는 문제를 확인했다. 눈 바깥 테두리를 고정한 채 볼만 줄이거나 앞으로 밀었던 두 후보는 꺾임이 악화돼 제외했다. 이후 눈 바깥 테두리·광대·관자 방향을 함께 보정하고, 곡면 안구의 X/Y 곡률을 일관되게 옮기며 속눈썹을 다시 맞췄다. 두상 전체 높이는 바꾸지 않았다.

같은 카메라의 렌더 표본에서 눈 중심 간격은 약245→233px, 입 높이 피부 폭은329→319px로 줄었다. 회색 홍채/눈 가로폭은 약0.46→0.54다. 실제 홍채 폭은56→57px, 눈 가로폭은121→106px이므로 이를 “홍채 자체가17% 커졌다”라고 표현하면 부정확하다. 원화의 수동 표본 약0.49–0.55는 기울기·가림을 포함한 근삿값이다.

바깥쪽 눈/얼굴 제어점은 최대 약6mm 변했고 기존47 shape key의 상대 변위와 UV·웨이트·토폴로지는 보존했다. 이 보존은 눈 감기·표정 연결의 완성을 뜻하지 않는다. 넓은 측면 볼 평면, 관자와 두개골 접합, 기존 눈 감기 때 속눈썹·페인트·안구의 분리 문제는 남아 있다. 현재 메시가 최종 애니메이션용 루프 구조라는 판정은 하지 않는다.

v17e–g 헤어에서는 뒤쪽 끝을 정리하고 작은 잔여61폴리곤을 제거했으며, 기존의 지나치게 어두운 표면을 따뜻한 회색으로 조정했다. 측면 정수리의 어두운 사각형은 돌출 메시가 아니라 헤어 틈으로 보이던 root lining임을 ray 검사로 확인했다. 해당 면의 색을 맞췄지만 틈에 가닥을 복원한 것은 아니다. 반묶음 매듭과 원본의 거친 표면도 미완료다.

## 실제 변경

1. 눈의 곡면 홍채에 고정 UV 셰이더를 적용하고 홍채 비율·동공·반사를 다듬었다. 공막 backface culling 수정은 유지했다. 코의 추가 국소 보정으로 이전 v17보다 측면 돌출을 약 1.1 mm 줄였다. 턱은 작게 완화했다.
2. 얼굴의 눈썹·눈 밑 색과 선·작은 입을 2048 UV 아틀라스에 베이크했다. 생성된 밑그림은 `front-paint-source*-not-model-render.png`이며 **실제 모델 렌더가 아니다**. 정확한 생성 프롬프트를 별도 보존했다. 런타임 카메라 투영이나 빌보드를 쓰지 않는다.
3. 눈썹보다 위의 두상을 최대 8 mm 높이고, 실제 Pixal 헤어의 접촉 부위를 맞췄다. 전체 피부와 숨겨진 원본 얼굴은 보존했다. 헤어 소유의 루트 라이닝을 별도 객체로 두었다.
4. 실제 Pixal의 앞머리·관자·잔머리·뒤쪽 웨이브를 재추출했다. 손상된 전면 원본 braid는 별도 3가닥 braid로 교체하고 실제 몸 표면과 반지름을 기준으로 배치했다. 초기의 과도한 전방 돌출은 채택하지 않았다.
5. 목덜미 수평 절단은 제작 코드의 넓은 높이 조건이 정상 머리까지 삭제한 회귀였다. 원본 문제라는 초기 설명을 철회했다. v17c에서는 보존한 원본 UV/폴리곤 대응으로 웨이브를 복구하고, 원래 braid의 좁은 중심선과 연결된 어두운 의상 조각만 구분했다. 제거한 source polygon ID와 이유를 기록했다.
6. 원본 헤어 UV와 2048 아틀라스를 남기고 새 paint UV + 4096 아틀라스를 추가했다. 원본 색만 emission bake로 옮겼으며, 노멀에 따른 툰 음영은 재질에서 계속 계산한다. 해상도 증가가 새로운 원화 디테일을 생성하는 것은 아니다.

## UV 비교의 범위

새 UV는 밀도 편차와 심한 왜곡의 꼬리를 줄였다. 대신 왜곡 중앙값은 약 1.01→1.18로 증가했고, UV 면적 사용률은 약 20.4%다. 최적 패킹이나 최종 페인팅 UV라고 주장하지 않는다. 1100 px 일반 뷰와 1400 px 확대 비교에서 넓은 디테일 손실·이음새 회귀는 관찰되지 않았다. 수치와 필터 한계는 `evidence/hair-uv-*.json`에 있다.

## 편집 구조와 후속 작업

피부, 눈, 헤어는 독립 소유다. 헤어 컬렉션은 실제 Pixal 본체, 루트 라이닝, 땋은 머리·끝·매듭을 포함한다. Crown / Fringe / Side_Nape / Rear_Waves / Left_Braid / Loose_Tips / Roots_Locked 영역을 두었지만, 이는 최종 본 웨이트나 충돌 검증 완료가 아니다.

단순한 반묶음 매듭, 일부 거친 끝과 원본 헤어 틈은 추가 손질 대상이다. 주 Pixal 메시의 앞/뒤 공간 그룹을 그대로 나누면 가닥을 잘라버리므로, 가닥 전체를 따르는 면 소유권이 필요하다. `evidence/hair-semantic-split-plan.md`에 실제 연결 성분과 경계 검사 결과를 기록했다. 원화들의 기울기·비율 차이가 있어 정밀한 두상 랜드마크 정합과 움직임 중 접촉은 미확정이다. 본 추가·물리·30fps 이벤트 클립은 이 조형/표면 단계 이후 작업이다.

## 검증 및 실행

실제 Blender 5.2.3 LTS에서 제작·UV 베이크·저장 후 재열기를 수행했다. 최종 비교는 정면·양사선·측면·후면, 두 배율의 hair on/off, 얼굴/헤어 UV, 클레이 및 눈 확대를 포함한다. 독립 아트 판정은 `INDEPENDENT_REVIEW.md`에 별도로 기록한다. 기술 보존이나 렌더 성공을 원화 닮음의 PASS로 대체하지 않는다.

`integrate-and-review.ps1`은 얼굴 레시피 1회→페인트 1회→읽기 전용 검토를 실행한다. `integrate_hair_collection_v17.py`는 얼굴을 다시 수정하지 않고 소유된 헤어 컬렉션 또는 주 헤어 객체만 교체한다. `tools/mia/blender/`의 v17/v17b/v17c 레시피는 중간 단계와 복구를 함께 남겼다. 재생성에는 manifest에 기록된 기존 로컬 Pixal/Blender 입력이 필요하며, 최종 native의 텍스처는 packed 상태다.

사이드에서 설치한 로컬 Blender MCP를 SDK로 연결해 실제 조회·파일 열기·통합 저장·다각도 캡처를 수행했다. `integrate_live_candidate.py`는 검증된 두 입력을 새 파일에 통합하며, 예상한 live 파일과 다르면 교체하지 않는다. 테스트 뷰 폐기는 사용자가 명시적으로 허용했다. Codex 네이티브 도구 목록에 새 MCP가 노출됐다는 주장은 하지 않는다.

원화는 [참조 인덱스](../../REFERENCE_INDEX.md)에 모았다. Desktop 체크아웃에 빠졌던 속옷 체형 시트·표정·확정 원화도 기존 파일을 덮어쓰지 않고 동기화했다. 생성된 체형 시트의 후보 상태와 사용자 재확인 디자인은 구분한다.
