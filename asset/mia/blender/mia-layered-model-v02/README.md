# Mia Anatomy v02

This is the frozen v13 anatomy stage for the Mia rebuild. It contains the single Face/Body anatomy result with the approved full bust retained. Source originals remain hidden and preserved in the native file.

The stage was independently reviewed from actual 216-view material/structure evidence: no collapse, gap, or severe intersection was found. T-pose hand and neck projection are recorded as follow-up notes.

The Face/Body basis uses the verified Victoria Rubin VRoid beta source for editable anime topology and morph structure. The original VRoid hair and wardrobe are not adopted. Mia likeness, hair, garments, accessories, rig and event animation remain separate gates.

This directory is ready for the next Hair stage. It is not a complete Mia model.

The anatomy review accepts this as a construction base. Final facial likeness is
still open: the user reaffirmed the narrow, heavy-lidded eyes, defined under-eye
tone, dry mouth and irregular charcoal waves in the expression sheet on
2026-10-31. A generic sample face with added makeup does not satisfy that art gate.

The face contains **42 shape-key blocks including Basis**. The historical audit
field `shape_key_43_count` was named incorrectly; the accompanying morph-count
erratum and source inventory record the actual preserved names and order.

Donor extraction must evaluate a visible disposable source copy before reading
its world transform. In this native file, archived Body, Face and Hair001 have
stale identity world matrices until evaluated, whereas their local transforms
and active copies match Mia's 180-degree Z frame. The read-only source-frame
probe records this measured registration; it is not a universal asset rotation.

See Mia_Anatomy_v02.provenance.json, the v02 anatomy audit directory, and its key-view evidence.
