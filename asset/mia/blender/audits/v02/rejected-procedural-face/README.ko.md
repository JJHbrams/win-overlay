# Mia 절차적 얼굴 실패 참조

`Mia_ProceduralFace_Rejected.blend`는 v15 실험을 그대로 보존한 파일이다. Mia 완성본이나 얼굴 승인 기반이 아니다. 정면과 측면 clay 이미지는 이 파일에서 실제 렌더한 key view이며 이미지 생성으로 대체하지 않았다.

v5/v8/v12의 216뷰와 독립 검토는 각각 그 버전에만 해당하며 얼굴 FAIL이었다. 최신 v15에 과거 검수 결과를 승계하지 않는다. 모든 후보·검사 원본은 `D:/ai/Mia3DWork/model-v02/anatomy/`에 보존한다.

새 제작은 권리가 검증된 anime 얼굴의 원래 눈·입 표정 구조와 부품/texture/toon을 바탕으로 진행한다. 이 파일의 procedural head를 다음 제작 원본으로 사용하지 않는다.
