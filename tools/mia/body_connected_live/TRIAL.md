# Broad connected design cage

The H static field joins and local cap/leaf patches remain unaccepted. Original
R3b is already a connected quad-dominant body/head, but its body-G compressed
breast return and old small06 boundary constraints are not valid shape targets.
This trial frees the complete torso/proximal-arm/lower-neck network while
holding the true head, its two control support rings, certified distal-arm
cycles and lower body. Raw IDs below3957 alone are not an anatomical body mask.

The first live operation is an explicit whole-control selection on a private
static posed copy; no deformation is applied by the selection helper. Original
47keys, threeUVs, materials, weights, drivers and native stay protected. The
copy has no expression rig/keys and is not production migration or ART approval.

The next broad deformation must use meridian arc-length around supported
breast/root volume, rather than a global heightfield across an undercut, and
connected shoulder/axillary control propagation. It must include the source
suprasternal notch, curved clavicle support and shallow fossae toward acromion;
no etched SCM tubes or use of the ink-anchor Z as a skeletal fact. Fine map
painting and final body/head proportions remain root-owned and deferred.

## Actual single trial, 2026-11-04

The original 888-control selection was shown in live Blender and approved only
for one design attempt. Factory-startup CPU evaluation of the original posed
private copy was bitexact at all80771 evaluated vertices; original native was
not changed. The first numerical solve stopped before output because plain CG
did not converge. Diagonal preconditioning solved the same constraints in228
iterations; this was not a shape-parameter search.

The single proposal used29 ordered front meridians (arc length above/below each
pole) against the supported H front envelope only,395 front observations,
30 roof observations from the source visibility evidence, and a coupled broad
bi-Laplacian displacement of the full888-control domain. Neck/clavicle cues
placed broad weak ridge/fossa/notch forms; they were explicitly anatomical
hypotheses, not measured bones. No failed cap or posterior-leaf geometry was
used as a target.

**Rejected.** Actual fixed-light before/after renders at front, profile, back,
oblique, high and low showed fuller breast projection but angular/pinched inner
and lower returns, poor axillary transition and insufficient shoulder/neck
continuity. The evaluated surface had51 triangle normals rotated over90deg in
the lower/inner return (Z1.195–1.241); that is a strain warning, not a claimed
self-intersection proof. Raw affected triangles included compressed return
IDs3577/3578/3581/3582/3594/3599. This failed radial correspondence + old return
chart combination does not prove a professional cannot sculpt the old cage.
It does satisfy the existing plan's condition to stop that mapping and replace
the upper-body interior flow once rather than continue small variants.

All original raw head/support controls, original47 keys and source raw body
were exact. Actual evaluated points at Z>=1.48 were bitexact;37 lower-neck
points at Z1.46512–1.47150 moved up to0.000255mm through post-modifier support.
This is reported rather than hidden by checking only Face690. Polygon loops
were exact. The evaluated MIA_BODY_V23_UV hash varied before geometry editing;
that layer is unverified, not certified from this trial. Main UVMap and the
underwear layer hashes were stable. No production UV/key/weight migration was
performed or approved.

The12 actual renders and four original-aspect source/visibility/before/after
boards are in canonical `.mia-cache/body-connected/actual-gray/`. They reuse
the existing common whole-height uniform SRT and original source crops;
reference aspect was not changed. Nominal drawing cameras are uncertain.
The private cage was then removed; root D visibility, source, camera, viewport
and context were restored by official MCP. Original native was never saved.

The next authorized design is one new upperbody flow with separate sternum,
breast bowl/return, anterior fold, posterior fold/floor/lat and shoulder–clavicle
charts. Original head/lower body and certified outside boundaries stay held.
It will not reuse this failed radial correspondence or old cap chart. New
weights, measured Armature inverse,47-key zero body deltas and chart-aware UV
migration remain later production checks after the design shape is selected.
